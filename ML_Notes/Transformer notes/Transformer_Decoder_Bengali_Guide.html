01 // INTUITION
🎯 সহজ ভাষায় পরিচিতি
🏠 বাস্তব জীবনের উদাহরণ — রান্নাঘরের সাথে তুলনা

কল্পনা করো তুমি একটি বড় রেস্তোরাঁয় কাজ করছ। রেস্তোরাঁর দুটো প্রধান অংশ আছে:

  • Encoder = রেসিপি বিশ্লেষক — কাস্টমারের অর্ডার (ইংরেজি মেনু) পড়ে বুঝে নেয় এবং শেফের জন্য বিস্তারিত নোট তৈরি করে।
  • Decoder = শেফ — সেই নোট দেখে একটু একটু করে রান্না করে প্লেটে পরিবেশন করে (হিন্দি অনুবাদ)।

Encoder যতক্ষণ পর্যন্ত তার কাজ শেষ না করে, Decoder কাজ শুরু করে না। Encoder সম্পূর্ণ "বোঝার কাজ" করে ফেলে, তারপর Decoder সেই বোঝার উপর ভিত্তি করে আউটপুট তৈরি করে।

🤔 কোন সমস্যা সমাধান করে?
  • একটি ভাষা থেকে অন্য ভাষায় অনুবাদ করা
  • Source sentence-এর context বুঝে Target sentence তৈরি করা
  • প্রতিটি শব্দ তৈরির সময় আগের শব্দগুলো মনে রাখা
  • Source ও Target-এর মধ্যে সঠিক সম্পর্ক স্থাপন করা
⚙️ Training vs Inference

এই গাইড Training-এর উপর focus করেছে।

Training-এ: সম্পূর্ণ output sentence একসাথে দেওয়া হয় (Non-autoregressive)

Inference-এ: একটি একটি করে token generate হয় (Autoregressive)

আর্কিটেকচার একই, কিন্তু কাজ করার পদ্ধতি আলাদা।

🎯 মূল উদাহরণ যা সারা গাইডে ব্যবহার হবে:

Input (English) → "We are friends"
Output (Hindi) → "हम दोस्त हैं" (হম দোস্ত হ্যাঁ)

Encoder ইংরেজি সেন্টেন্স প্রসেস করবে। Decoder হিন্দি সেন্টেন্স তৈরি করবে।

03 // INPUT PROCESSING
📥 Input Block — ৪টি ধাপে প্রস্তুতি

Decoder-এ কোনো data পাঠানোর আগে সেই data কে প্রস্তুত করতে হয়। Output sentence (হিন্দি) কে ৪টি ধাপে process করে Decoder-এ পাঠানোর উপযুক্ত করা হয়।

আমাদের হিন্দি সেন্টেন্স: "हम दोस्त हैं" (হম দোস্ত হ্যাঁ)
এই সেন্টেন্সটাকে ধাপে ধাপে process করা হবে।
1
Right Shifting (শিফটিং)

সেন্টেন্সের শুরুতে একটি বিশেষ <START> token যোগ করা হয়। এই token training process শুরু হওয়ার সংকেত দেয় — একটি flag-এর মতো কাজ করে।

"हम दोस्त हैं" → "<START> हम दोस्त हैं"

এই কারণেই একে "Right Shift" বলা হয় — পুরো sentence একটু ডানদিকে সরে যায়, বামে START token বসে।

2
Tokenization (টোকেনাইজেশন)

সেন্টেন্সকে ছোট ছোট অংশে ভাগ করা হয়। আমরা সহজ পদ্ধতি ব্যবহার করছি — প্রতিটি শব্দ একটি token।

"<START> हम दोस्त हैं" ↓ Token 1: <START> Token 2: हम Token 3: दोस्त Token 4: हैं মোট = ৪টি Token

Tokenization technique বিভিন্ন হতে পারে — word-level, byte-pair encoding (BPE), subword ইত্যাদি। এখানে word-level ব্যবহার করা হচ্ছে।

3
Embedding (এম্বেডিং লেয়ার)

Machine শব্দ বোঝে না, সংখ্যা বোঝে। Embedding layer প্রতিটি token কে একটি 512-dimensional vector-এ রূপান্তর করে।

<START> → e1 [v₁, v₂, v₃, ..., v₅₁₂] ← 512টি সংখ্যা हम → e2 [v₁, v₂, v₃, ..., v₅₁₂] ← 512টি সংখ্যা दोस्त → e3 [v₁, v₂, v₃, ..., v₅₁₂] ← 512টি সংখ্যা हैं → e4 [v₁, v₂, v₃, ..., v₅₁₂] ← 512টি সংখ্যা

Original paper-এ প্রতিটি vector ৫১২ dimensional। এই vectors গুলো trainable — training-এর সময় এগুলো optimize হয়।

4
Positional Encoding (অবস্থান এনকোডিং)

Embedding vector কোন শব্দটি কোথায় ছিল সে তথ্য রাখে না। "হম দোস্ত হ্যাঁ" আর "দোস্ত হম হ্যাঁ" — দুটো ভিন্ন অর্থ, কিন্তু embedding দেখে বোঝার উপায় নেই। Positional Encoding এই সমস্যা সমাধান করে।

প্রতিটি Position-এর জন্য আলাদা vector তৈরি হয়: Position 1: p1 [512-dimensional] Position 2: p2 [512-dimensional] Position 3: p3 [512-dimensional] Position 4: p4 [512-dimensional] তারপর Addition: ━━━━━━━━━━━━━━━━━━━━━━━━━━━━ e1 + p1 = x1 (START-এর final vector) e2 + p2 = x2 (हम-এর final vector) e3 + p3 = x3 (दोस्त-এর final vector) e4 + p4 = x4 (हैं-এর final vector)

এই x1, x2, x3, x4 — এই ৪টি vector-ই Decoder-এর First Block-এ পাঠানো হবে।

১ Right Shifting হিন্দি sentence <START> + sentence
২ Tokenization Complete string 4টি individual token
৩ Embedding Tokens (words) 4 × 512-dim vectors (e1..e4)

05 // MASKED SELF ATTENTION
🎭 Masked Multi-Head Self Attention

এই block Normal Multi-Head Self Attention-এর মতোই কাজ করে, একটাই বড় পার্থক্য — এখানে Masking implement করা হয়।

Masking কেন দরকার?

🧠 মূল ধারণা

Training-এর সময় আমরা চাই Decoder যেন ভবিষ্যতের শব্দ দেখে "cheating" না করে। অর্থাৎ, "হম" শব্দ predict করার সময় Decoder যেন শুধু "<START>" দেখতে পারে, "দোস্ত" বা "হ্যাঁ" দেখতে না পারে।

Masking কীভাবে কাজ করে?

প্রতিটি Token-এর Contextual Embedding তৈরির সময়: z1 তৈরি করতে: শুধু <START> দেখতে পাবে × हम, × दोस्त, × हैं — masked! z2 তৈরি করতে: <START> + हम দেখতে পাবে × दोस्त, × हैं — masked! z3 তৈরি করতে: <START> + हम + दोस्त দেখতে পাবে × हैं — masked! z4 তৈরি করতে: <START> + हम + दोस्त + हैं — সব দেখতে পাবে (এটাই শেষ token, কিছু mask করা হয় না) সরল উপস্থাপনা (Attention Matrix): START हम दोस्त हैं START [ ✓ ✗ ✗ ✗ ] हम [ ✓ ✓ ✗ ✗ ] दोस्त [ ✓ ✓ ✓ ✗ ] हैं [ ✓ ✓ ✓ ✓ ]

Output কী আসে?

প্রতিটি Input vector (x) এর জন্য একটি Contextual Embedding (z) তৈরি হয়:

x1 → z1    x2 → z2    x3 → z3    x4 → z4

এই z vectors গুলো ৫১২ dimensional। এরা x vectors-এর চেয়ে "smarter" — কারণ এরা context বোঝে।

Add & Norm — Residual Connection

Masked Attention-এর পরে একটি গুরুত্বপূর্ণ কাজ হয়:

A
Addition (যোগ)

Residual/Skip Connection: x1..x4 (original input) এবং z1..z4 (attention output) যোগ করা হয়।

z1' = z1 + x1    z2' = z2 + x2    z3' = z3 + x3    z4' = z4 + x4

এটা করা হয় কারণ original information যাতে হারিয়ে না যায়।

B
Layer Normalization (নর্মালাইজেশন)

z1'..z4' কে Layer Norm Layer-এ পাঠানো হয়। প্রতিটি vector-এর জন্য mean (μ) এবং standard deviation (σ) calculate করে normalize করা হয়।

কেন normalize করা হয়? অনেক multiplication ও addition-এর পরে কিছু বড় number তৈরি হতে পারে যা training unstable করে দেয়। Layer Normalization training stable রাখে।

Layer Norm-এর পরে আমরা পাই: z1_norm, z2_norm, z3_norm, z4_norm — এগুলো এখন Cross Attention Block-এ যাবে।

06 // CROSS ATTENTION
🔗 Cross Attention — Encoder-Decoder এর সংলাপ
Cross Attention হল পুরো Decoder Architecture-এর সবচেয়ে interesting অংশ!
এখানে ইংরেজি sentence (Encoder থেকে) এবং হিন্দি sentence (Decoder থেকে) — দুটো আলাদা সিকোয়েন্স একসাথে কথা বলে।

সাধারণ Self Attention বনাম Cross Attention

Normal Self Attention

Input: একটি মাত্র sequence

Query, Key, Value: সবই একই sequence থেকে আসে

উদাহরণ: "হম দোস্ত হ্যাঁ" — সবাই নিজেদের মধ্যে কথা বলে

Cross Attention

Input: দুটি sequence

Query: Decoder থেকে আসে (হিন্দি)

Key + Value: Encoder থেকে আসে (ইংরেজি)

উদাহরণ: হিন্দি tokens ইংরেজি tokens-এর সাথে কথা বলে

Cross Attention এর Step-by-Step Process

Cross Attention Block-এ দুই দিক থেকে Input আসে: ┌─────────────────────┐ ┌─────────────────────────┐ │ ENCODER OUTPUT │ │ MASKED ATTENTION │ │ (ইংরেজি tokens) │ │ OUTPUT (হিন্দি tokens) │ │ │ │ │ │ encoder_embed[1..n]│ │ z1_norm, z2_norm, │ │ (Encoder-এর final │ │ z3_norm, z4_norm │ │ contextual embed) │ │ │ └──────────┬──────────┘ └────────────┬────────────┘ │ │ ↓ ↓ KEY (K) + VALUE (V) QUERY (Q) vectors vectors তৈরি হয় তৈরি হয় │ │ └──────────────┬──────────────┘ │ ↓ ┌────────────────┐ │ CROSS ATTENTION │ │ Mechanism │ │ │ │ similarity(Q,K)│ │ weighted sum │ │ with V │ └───────┬────────┘ │ ↓ zc1, zc2, zc3, zc4 (Cross Attention Output) প্রতিটি হিন্দি token এখন ইংরেজির context জানে!
💡 Cross Attention কী করে?

প্রতিটি হিন্দি token প্রতিটি ইংরেজি token-এর সাথে similarity score calculate করে। উদাহরণস্বরূপ, "দোস্ত" (দোস্ত = friend) token সবচেয়ে বেশি "friends" ইংরেজি token-এর দিকে attention দেবে। এভাবে translation alignment তৈরি হয়।

Cross Attention-এর পরে Add & Norm

আবারো Residual Connection + Layer Normalization:

zc' = zc + z_norm (masked attention output)
zc_norm = LayerNorm(zc')

Output: zc1_norm, zc2_norm, zc3_norm, zc4_norm → এগুলো Feed Forward Block-এ যাবে।

07 // FEED FORWARD
🧠 Feed Forward Neural Network

এই block Encoder-এর Feed Forward block-এর মতোই — সম্পূর্ণ copy-paste architecture, শুধু parameters আলাদা।

Architecture

Input Layer Hidden Layer Output Layer ━━━━━━━━━━━ ━━━━━━━━━━━━━ ━━━━━━━━━━━━━ 512 neurons →→→ 2048 neurons →→→ 512 neurons Activation: ReLU Linear Weights: W1 (512×2048) Weights: W2 (2048×512) Bias: b1 (2048) Bias: b2 (512)

Batch Processing — একসাথে ৪টি Vector

আমাদের ৪টি vector আছে। এগুলোকে একটি Matrix-এ stack করে একসাথে পাঠানো হয়:

Step 1: Matrix তৈরি ━━━━━━━━━━━━━━━━━━━━ [zc1_norm] Shape: (4 × 512) [zc2_norm] → Matrix Z [zc3_norm] [zc4_norm] Step 2: First Layer (Expansion) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Z · W1 + b1 = (4×512) · (512×2048) + (2048,) = (4×2048) ← dimension বাড়ল! Step 3: ReLU Activation ━━━━━━━━━━━━━━━━━━━━━━ ReLU(4×2048) = (4×2048) → সব negative values শূন্য হয়ে যায় → Non-linearity introduce হয় Step 4: Second Layer (Compression) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ReLU_output · W2 + b2 = (4×2048) · (2048×512) + (512,) = (4×512) ← আবার 512-dim! Final Output: y1, y2, y3, y4 প্রতিটি 512-dimensional, কিন্তু এখন non-linear information capture করতে পারে!

কেন FFNN দরকার?

Attention mechanism linear patterns ধরতে পারে। কিন্তু language-এ অনেক non-linear patterns আছে।

ReLU activation দিয়ে FFNN সেই non-linear patterns capture করতে পারে।

মোটকথা: Attention = "কোথায় দেখব", FFNN = "দেখে কী বুঝব"

FFNN-এর পরে Add & Norm

y' = y + zc_norm (cross attention output)
y_norm = LayerNorm(y')

Final Output of First Decoder Block: y1_norm, y2_norm, y3_norm, y4_norm

08 // 6 BLOCKS
📚 6টি Block Stacking — পুরো Decoder

Block 1-এর কাজ বোঝা গেলে বাকি ৫টি Block আপনাআপনি বোঝা যায়, কারণ সব Block-এর Architecture এক।

Input (x1..x4) │ ▼ ┌─────────────────────────────────────────┐ │ DECODER BLOCK 1 │ │ ┌──────────────┐ ┌────────────────┐ │ │ │Masked Self │ │Cross Attention │ │ │ │Attention │ │(Encoder Input) │ │ │ └──────────────┘ └────────────────┘ │ │ ┌──────────────┐ │ │ │Feed Forward │ Add & Norm ×3 │ │ └──────────────┘ │ └─────────────────┬───────────────────────┘ │ y1_norm..y4_norm ▼ ┌─────────────────────────────────────────┐ │ DECODER BLOCK 2 (same architecture) │ │ (Different Parameters!) │ └─────────────────┬───────────────────────┘ │ ▼ Block 3 │ ▼ Block 4 │ ▼ Block 5 │ ▼ ┌─────────────────────────────────────────┐ │ DECODER BLOCK 6 (Last Block) │ └─────────────────┬───────────────────────┘ │ ▼ yf1_norm, yf2_norm, yf3_norm, yf4_norm (Final Output — f = final) │ ▼ OUTPUT BLOCK →
প্রতিটি Block-এ Encoder-এর আউটপুট আবার ব্যবহার হয়!
প্রতিটি Decoder Block-এর Cross Attention Layer-এ Encoder-এর final output (encoder embeddings) Key ও Value হিসেবে ব্যবহৃত হয়। তাই সব ৬টি Block-ই ইংরেজি sentence-এর context পায়।
09 // OUTPUT BLOCK
🎯 Output Block — Linear + Softmax

৬টি Decoder Block পার করার পরে আমরা পাই yf1_norm..yf4_norm। এখন এই vectors থেকে actual Hindi words predict করতে হবে।

Vocabulary কী?

📚 Vocabulary তৈরির Process

আমাদের ৫০০০ হিন্দি-ইংরেজি sentence pair আছে। হিন্দি column-এর সব sentence থেকে unique words collect করা হয়।

মান লো: 5000 হিন্দি sentence → 10,000 unique হিন্দি শব্দ শব্দ ১: मैं (Index: 0) শব্দ ২: बढ़िया (Index: 1) শব্দ ৩: हूँ (Index: 2) শব্দ ৪: हम (Index: 3) শব্দ ৫: दोस्त (Index: 4) শব্দ ৬: हैं (Index: 5) ... শব্দ 10000: ... (Index: 9999) V = 10,000 ← এটাই Vocabulary Size

Linear Layer Architecture

Linear Layer: ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Input: 512-dimensional vector Output: V-dimensional vector (V = 10,000) Neurons: V = 10,000 → Neuron 1 represents: মৈঁ (মান) → Neuron 2 represents: বড়িয়া → Neuron 3 represents: হূঁ → Neuron 4 represents: হম ← আমাদের দরকার এটা → Neuron 5 represents: দোস্ত ← আর এটা → Neuron 6 represents: হ্যাঁ ← আর এটা ... → Neuron 10000 represents: last word Weights: W3 (512 × 10,000) = 5,120,000 parameters! Bias: b3 (10,000)

Softmax — Probability Distribution

Linear Layer Output (Un-normalized): ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ [3.2, 6.1, 0.4, 8.7, 2.1, 1.3, ..., 0.8] ← V=10,000 numbers, যেকোনো value হতে পারে After Softmax: ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ সব numbers → Probability (0 থেকে 1) সবগুলোর যোগফল = 1.0 [0.01, 0.03, 0.01, 0.82, 0.05, 0.02, ..., 0.01] ↑ "হম" এর probability = 82%! → এটাই predicted word Example for yf1_norm (<START> position): "হম" → probability 0.82 (সর্বোচ্চ) → Decoder predicts "হম" as first output word ✓

সব Tokens-এর জন্য Parallel Prediction

Position 1 (START → ?): yf1_norm → Linear → Softmax → "হম" (সর্বোচ্চ prob) Position 2 (হম → ?): yf2_norm → Linear → Softmax → "দোস্ত" (সর্বোচ্চ prob) Position 3 (দোস্ত → ?): yf3_norm → Linear → Softmax → "হ্যাঁ" (সর্বোচ্চ prob) Position 4 (হ্যাঁ → ?): yf4_norm → Linear → Softmax → <END> (সর্বোচ্চ prob) Training-এ এই predicted words কে Ground Truth-এর সাথে compare করা হয় এবং Cross Entropy Loss calculate করে Backpropagation চালানো হয়।
📊 Training Process-এ কী হয়?
  • Predicted probabilities এবং actual labels (ground truth) এর মধ্যে Cross Entropy Loss calculate করা হয়।
  • Loss কমানোর জন্য Backpropagation করা হয়।
  • সব layers-এর Parameters update হয়।
  • বারবার এই process হয় যতক্ষণ না model সঠিকভাবে predict করতে পারে।

🔑 মূল বিষয়গুলো — Key Takeaways
①
Input Processing (৪ ধাপ)

Right Shifting → Tokenization → Embedding (512-dim) → Positional Encoding → x1..x4

②
Masked Self Attention

Future tokens mask করা হয়। প্রতিটি position শুধু আগের positions দেখতে পারে।

③
Cross Attention

Query Decoder থেকে, Key+Value Encoder থেকে। Source-Target alignment তৈরি হয়।

④
Feed Forward Neural Network

512 → 2048 (ReLU) → 512। Non-linear features capture করে।

⑤
6 Blocks Stacking

একই architecture ৬ বার। প্রতিটি Block-এর parameters আলাদা।

⑥
Output Block

Linear (512→V) + Softmax → Word Probabilities → Training Loss

পরবর্তী ভিডিও / গাইড: Inference (Prediction) Time-এ Decoder কীভাবে কাজ করে — Auto-regressive mode, যেখানে token by token generate হয়। Encoder-এর structure একই থাকবে কিন্তু Decoder Auto-regressive পদ্ধতিতে চলবে।
