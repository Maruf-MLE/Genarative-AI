১. Normalization কী এবং কেন দরকার? (Intuition)

বাস্তব জীবনের উদাহরণ — পরীক্ষার নম্বর

মনে করো, একটি ক্লাসে পদার্থবিজ্ঞানে নম্বর ০–১০০ এর মধ্যে, আর গণিতে ০–১০ এর মধ্যে। যদি এই দুটি বিষয়ের নম্বর একসাথে কোনো model-এ দেওয়া হয়, তাহলে model পদার্থবিজ্ঞানকে "বেশি গুরুত্বপূর্ণ" মনে করবে শুধুমাত্র scale বড় বলে। Normalization এই সমস্যা সমাধান করে — সব নম্বরকে একই range-এ নিয়ে আসে।

Deep Learning-এ Normalization মানে:

Data-কে এমনভাবে transform করা যাতে নির্দিষ্ট statistical properties থাকে। যেমন: Mean = 0, Standard Deviation = 1।

Deep Learning-এ দুটি জিনিসে normalization প্রয়োগ করা যায়:

① Input Data-তে

Model-এ পাঠানো feature values গুলোকে normalize করা হয়। এটি আমরা Machine Learning থেকেই জানি — Standardization বা Min-Max Scaling।

② Hidden Layer Activations-এ

Neural Network-এর hidden layer গুলোর output (activation) normalize করা হয়। এটিই আজকের মূল আলোচনা।

⚡
১.১ Normalization-এর ৪টি উপকার
  • ১
    Training Stability উন্নত হয়

    Weight অনেক বড় হয়ে গেলে activation-ও বড় হয়, model দ্রুত converge করে না। Normalization এই extreme values কমিয়ে training স্থিতিশীল রাখে এবং Gradient Explosion রোধ করে।

  • ২
    দ্রুত Convergence

    Gradient-গুলোর magnitude consistent হলে model দ্রুত converge করে। Normalization ঠিক এটাই নিশ্চিত করে।

  • ৩
    Internal Covariate Shift সমস্যা সমাধান

    Training চলার সময় weights পরিবর্তিত হওয়ার কারণে hidden layer-এ input distribution পরিবর্তন হতে থাকে — এটিই Internal Covariate Shift। Normalization এই পরিবর্তন নিয়ন্ত্রণে রাখে।

  • ৪
    Regularization Effect

    কিছু normalization technique (বিশেষত Batch Normalization) হালকা regularization effect দেয়, overfitting কমাতে সাহায্য করে।

🔄
২. Covariate Shift ও Internal Covariate Shift

Covariate Shift কী?

Training-এ এক ধরনের data দিয়ে model train করা হল, কিন্তু prediction করতে গিয়ে ভিন্ন distribution-এর data এলে model ভালো কাজ করে না।

উদাহরণ:

Flower classification model শুধু লাল গোলাপ দিয়ে train করা হল। কিন্তু prediction-এ হলুদ গোলাপ, সাদা গোলাপ দেওয়া হলে distribution আলাদা — তাই model ব্যর্থ হবে।

Internal Covariate Shift কী?

এটি Neural Network-এর ভেতরে ঘটে। Backpropagation চলার সময় weights পরিবর্তিত হয়। এর ফলে পরবর্তী layer যে input পায়, তার distribution ক্রমাগত পরিবর্তন হতে থাকে।

┌─────────────────────────────────────────────────────────┐ │ Internal Covariate Shift │ ├─────────────────────────────────────────────────────────┤ │ │ │ Input → [Hidden Layer 1] → [Hidden Layer 2] → Output │ │ ↑ ↑ │ │ w₁, w₂ আছে এর input আসে │ │ Hidden Layer 1 থেকে │ │ │ │ Backprop চলতে থাকলে w₁, w₂ পরিবর্তন হয় │ │ → Hidden Layer 1-এর output বদলায় │ │ → Hidden Layer 2-এর INPUT-ও বদলায় │ │ → Hidden Layer 2 সবসময় নতুন distribution দেখছে │ │ → এটাই Internal Covariate Shift! │ │ │ │ সমাধান: Activation-গুলো Normalize করা │ └─────────────────────────────────────────────────────────┘

৩. Batch Normalization — বিস্তারিত Process
📋
Setup (উদাহরণ)

একটি Dataset আছে যেখানে ২টি feature: f1 এবং f2। একটি Neural Network: Input Layer → Hidden Layer (৩টি node) → Output Layer। Batch Size = 5 (একসাথে ৫টি row যাবে)।

Dataset: ┌────┬────┬────────┐ │ f1 │ f2 │ target │ ├────┼────┼────────┤ │ 2 │ 3 │ ... │ ← row 1 │ 1 │ 1 │ ... │ ← row 2 │ 4 │ 2 │ ... │ ← row 3 │ 3 │ 5 │ ... │ ← row 4 │ 6 │ 1 │ ... │ ← row 5 └────┴────┴────────┘ Neural Network: f1 ──┐ ├──→ [node1 (z1)] ──→ f2 ──┤ ├──→ [node2 (z2)] ──→ Output │ └──→ [node3 (z3)] ──→

Step-by-Step Process:

  • ১
    Pre-activation (Weighted Sum) কালকুলেট করো

    প্রতিটি row এর জন্য, প্রতিটি node-এর weighted sum বের করো:

    z1 = (f1 × w1) + (f2 × w2) + b1

    এভাবে সব ৫টি row-এর জন্য z1, z2, z3 কালকুলেট করলে একটি table তৈরি হয়:

Pre-activation table (উদাহরণ মান): ┌───────┬────┬────┬────┐ │ Row │ z1 │ z2 │ z3 │ ├───────┼────┼────┼────┤ │ row 1 │ 7 │ 5 │ 4 │ │ row 2 │ 2 │ 3 │ 4 │ │ row 3 │ 1 │ 7 │ 7 │ │ row 4 │ 5 │ 3 │ 5 │ │ row 5 │ 3 │ 6 │ 3 │ └───────┴────┴────┴────┘ Batch Normalization করে COLUMN অনুযায়ী (↓ direction): z1 column → μ₁ ও σ₁ বের করো z2 column → μ₂ ও σ₂ বের করো z3 column → μ₃ ও σ₃ বের করো
  • ২
    প্রতিটি Column-এর μ (mean) ও σ (std) বের করো
    μ₁ = mean(z1 column), σ₁ = std(z1 column)
  • ৩
    Normalize করো (Standardize)
    ẑ = (z - μ) / σ

    যেমন row 1-এর z1 = 7 হলে: ẑ = (7 - μ₁) / σ₁

  • ৪
    Scale & Shift (γ ও β দিয়ে)

    প্রতিটি node-এর নিজস্ব learnable parameter γ (gamma) ও β (beta) আছে। এগুলো initially γ=1, β=0 হয়, training-এ শেখে।

    output = γ × ẑ + β

    Node 1 এর জন্য: γ₁, β₁ | Node 2: γ₂, β₂ | Node 3: γ₃, β₃

  • ৫
    Activation Function-এ পাঠাও

    Normalize করা value activation function (ReLU, sigmoid ইত্যাদি)-এ যায়, তারপর সেটাই পরের layer-এর input।

🔑 মূল কথা — Batch Normalization normalize করে ACROSS THE BATCH (column অনুযায়ী, ↓ direction)।
❌
৪. Transformer-এ Batch Norm কেন কাজ করে না?

মূল সমস্যা: Sequential Data + Padding

Transformer Self-Attention-এর সাথে Batch Normalization ভালো কাজ করে না। এর কারণ sequential data-তে padding-এর প্রয়োজন পড়ে।

পুরো সমস্যাটি বুঝি — একটি উদাহরণ দিয়ে:

📝
Setup: Sentiment Analysis

Dataset-এ ৪টি sentence আছে। Batch size = 2 (একসাথে ২টি sentence পাঠাব)।
Embedding dimension = 3 (প্রতিটি word 3D vector)।

Dataset: Sentence 1: "Hi Nitesh" → ২টি word Sentence 2: "How are you today" → ৪টি word Sentence 3: "I am good" → ৩টি word Sentence 4: "You?" → ১টি word First Batch: Sentence 1 + Sentence 2 একসাথে যাবে সমস্যা: Sentence 1-এ ২টি word, Sentence 2-এ ৪টি word Self-Attention-এ equal-length input দরকার! সমাধান: PADDING ব্যবহার করো Sentence 1: "Hi Nitesh [PAD] [PAD]" → ৪টি word (2টি zero vector যোগ) Sentence 2: "How are you today" → ৪টি word

Self-Attention-এর Output:

Self-Attention-এ দুটি matrix (4×3) পাঠানো হল। Output-ও দুটি 4×3 matrix পাবো। PAD token-গুলোর output = zero (কারণ zero × যেকোনো সংখ্যা = zero)।

Output (Contextual Embeddings), ২টি matrix স্ট্যাক করলে: dim-1 dim-2 dim-3 word-1 [ 6.5 | 2.4 | 99.2 ] ← Sentence 1, word "Hi" word-2 [ 3.1 | 7.8 | 1.5 ] ← Sentence 1, word "Nitesh" [PAD] [ 0.0 | 0.0 | 0.0 ] ← ⚠️ PADDING (আসল data না!) [PAD] [ 0.0 | 0.0 | 0.0 ] ← ⚠️ PADDING (আসল data না!) word-1 [ 4.2 | 8.9 | 2.3 ] ← Sentence 2, word "How" word-2 [ 5.5 | 1.2 | 67.4 ] ← Sentence 2, word "are" word-3 [ 9.1 | 3.3 | 4.8 ] ← Sentence 2, word "you" word-4 [ 2.7 | 6.6 | 11.2 ] ← Sentence 2, word "today" Batch Norm করতে গেলে COLUMN (dim) অনুযায়ী μ, σ বের করতে হবে ↓ dim-1: mean(6.5, 3.1, 0.0, 0.0, 4.2, 5.5, 9.1, 2.7) ↑ এখানে 0.0 এবং 0.0 আছে যেগুলো REAL DATA নয়, শুধু PADDING! 🚨 সমস্যা: এই zero values mean ও std কে distort করছে!
🚨 মূল সমস্যা কী?

যদি batch size 32 হয় এবং সবচেয়ে বড় sentence 100 word-এর হয়, কিন্তু বাকিগুলো গড়ে 30 word-এর — তাহলে প্রতিটি sentence-এ 70টি করে PADDING vector (সব zero) থাকবে! এই অসংখ্য artificial zero গুলো mean ও std-এর true representation নষ্ট করে দেবে। Batch Normalization-এর μ ও σ তখন আর data-র সত্যিকার চিত্র দেখাবে না।

🎓
উপসংহার

Padding-এর কারণে তৈরি হওয়া zero values batch-এর statistics (μ, σ) distort করে। তাই Sequential data-তে Batch Normalization প্রয়োগ করা যায় না। এটাই Transformer-এ Batch Norm ব্যবহার না করার কারণ।

✅
৫. Layer Normalization — সমাধান

Layer Normalization-এর মূল পার্থক্য

Batch Normalization যেখানে column অনুযায়ী (batch জুড়ে) normalize করে, সেখানে Layer Normalization করে row অনুযায়ী (feature জুড়ে)।

BATCH NORMALIZATION: LAYER NORMALIZATION: normalize করে ↓ direction-এ normalize করে → direction-এ dim1 dim2 dim3 dim1 dim2 dim3 row1 [ 7 | 5 | 4 ] ────→ row1 [ 7 | 5 | 4 ] → μ₁, σ₁ row2 [ 2 | 3 | 4 ] row2 [ 2 | 3 | 4 ] → μ₂, σ₂ row3 [ 1 | 7 | 7 ] row3 [ 1 | 7 | 7 ] → μ₃, σ₃ row4 [ 5 | 3 | 5 ] row4 [ 5 | 3 | 5 ] → μ₄, σ₄ row5 [ 3 | 6 | 3 ] row5 [ 3 | 6 | 3 ] → μ₅, σ₅ ↓ ↓ ↓ ↓ μ₁ μ₂ μ₃ (batch statistics) (প্রতিটি row স্বতন্ত্র!)

Layer Normalization-এর Step-by-Step Process:

  • ১
    প্রতিটি Row-এর নিজস্ব μ ও σ বের করো

    Row-1 (data point 1): সেই row-এর সব feature value দিয়ে μ₁ ও σ₁ বের করো।

    μ₁ = mean(z1, z2, z3) for row 1 only
    σ₁ = std(z1, z2, z3) for row 1 only
  • ২
    প্রতিটি Value Normalize করো

    Row-1-এর z1 normalize করতে:

    ẑ₁₁ = (z1_row1 - μ₁) / σ₁

    একইভাবে সেই row-এর বাকি values-গুলো: z2_row1 ও z3_row1 normalize করো।

  • ৩
    Scale & Shift: প্রতিটি Dimension-এর γ ও β

    Batch Norm-এর মতো এখানেও learnable parameters আছে। তবে এখানে প্রতিটি embedding dimension-এর জন্য γ ও β।

    output = γ_dim × ẑ + β_dim

    dim-1 এর জন্য: γ₁, β₁ | dim-2: γ₂, β₂ | dim-3: γ₃, β₃

  • ৪
    সব Rows-এর জন্য একই Process পুনরাবৃত্তি

    Row-2 এর জন্য আলাদা μ₂, σ₂ বের করে আলাদাভাবে normalize। Row-3, Row-4... সব স্বতন্ত্রভাবে।

🎯
৬. Transformer-এ Layer Norm কেন কাজ করে?

আগের উদাহরণে ফিরে যাই — Sentence 1 ও Sentence 2 সহ Padding-এর output matrix:

Self-Attention Output (stacked): dim-1 dim-2 dim-3 Layer Norm → word-1 [ 6.5 | 2.4 | 99.2 ] → μ₁ = mean(6.5, 2.4, 99.2), σ₁ = std(...) word-2 [ 3.1 | 7.8 | 1.5 ] → μ₂ = mean(3.1, 7.8, 1.5), σ₂ = std(...) [PAD] [ 0.0 | 0.0 | 0.0 ] → μ₃ = mean(0,0,0) = 0, σ₃ = 0 [PAD] [ 0.0 | 0.0 | 0.0 ] → μ₄ = mean(0,0,0) = 0, σ₄ = 0 word-1 [ 4.2 | 8.9 | 2.3 ] → μ₅ = mean(4.2, 8.9, 2.3) word-2 [ 5.5 | 1.2 | 67.4 ] → μ₆ = mean(5.5, 1.2, 67.4) word-3 [ 9.1 | 3.3 | 4.8 ] → μ₇ = mean(9.1, 3.3, 4.8) word-4 [ 2.7 | 6.6 | 11.2 ] → μ₈ = mean(2.7, 6.6, 11.2) ✅ প্রতিটি ROW স্বতন্ত্রভাবে normalize হচ্ছে! ✅ PAD rows শুধু নিজেদের মধ্যে নিজেরাই normalize হচ্ছে (0/0 → 0) ✅ PAD, আসল data-র statistics-কে প্রভাবিত করছে না!
🎉 সমাধান!

Layer Normalization-এ প্রতিটি row (প্রতিটি word/token) নিজের features দিয়ে নিজেই normalize হয়। PAD token-গুলো শুধু নিজেদের মধ্যে normalize হয় (0 - 0 / 0 = 0), এবং আসল data-র statistics কে কোনোভাবেই distort করে না। এটাই Layer Normalization-এর সবচেয়ে বড় সুবিধা Transformer-এ।

৮. Batch Norm vs Layer Norm — তুলনামূলক সারসংক্ষেপ
বৈশিষ্ট্য Batch Normalization Layer Normalization
Normalize করে Batch জুড়ে (column অনুযায়ী, ↓) Feature জুড়ে (row অনুযায়ী, →)
μ, σ বের হয় প্রতিটি feature-এর জন্য (batch থেকে) প্রতিটি data point-এর জন্য (features থেকে)
γ, β কোথায় প্রতিটি node/feature-এর জন্য প্রতিটি embedding dimension-এর জন্য
Sequential Data ❌ Padding-এর কারণে ব্যর্থ ✅ Padding affect করে না
Transformer-এ ব্যবহার ❌ ব্যবহার হয় না ✅ ব্যবহার হয় (Add & Norm step)
Variable-length input ❌ সমস্যা আছে ✅ কোনো সমস্যা নেই
Batch size dependency হ্যাঁ — batch size-এর উপর নির্ভরশীল না — প্রতিটি sample স্বতন্ত্র

৯. Mathematical Formula Summary

Batch Normalization

μ_j = (1/N) × Σ z_ij (j-th feature, N samples) σ_j = sqrt((1/N) × Σ(z_ij - μ_j)²) ẑ_ij = (z_ij - μ_j) / σ_j output = γ_j × ẑ_ij + β_j

Layer Normalization

μ_i = (1/D) × Σ z_ij (i-th sample, D features) σ_i = sqrt((1/D) × Σ(z_ij - μ_i)²) ẑ_ij = (z_ij - μ_i) / σ_i output = γ_j × ẑ_ij + β_j
💡 একটু সূক্ষ্ম পার্থক্য লক্ষ্য করো:

Batch Norm-এ μ ও σ-এর subscript হল j (feature index)।
Layer Norm-এ μ ও σ-এর subscript হল i (sample/row index)।
এই একটি পার্থক্যই পুরো normalization direction বদলে দেয়।

১০. মূল শিক্ষা — যা মনে রাখতে হবে

সবচেয়ে গুরুত্বপূর্ণ ৫টি Point

  • ১
    Normalization কেন দরকার?

    Training stability, faster convergence, internal covariate shift সমাধান, এবং regularization effect।

  • ২
    Batch Norm কীভাবে কাজ করে?

    Batch জুড়ে প্রতিটি feature (column) আলাদাভাবে normalize করে। প্রতিটি node-এর নিজস্ব γ, β আছে।

  • ৩
    Transformer-এ Batch Norm কেন নয়?

    Sequential data-তে padding (zero vectors) অনেক বেশি থাকে। এই কৃত্রিম শূন্যগুলো batch statistics (μ, σ) কে distort করে।

  • ৪
    Layer Norm কীভাবে সমাধান করে?

    প্রতিটি row (প্রতিটি token) নিজের features দিয়ে নিজে normalize হয়। Padding শুধু নিজেকে affect করে, অন্যদের statistics নষ্ট করে না।

  • ৫
    মূল পার্থক্য এক লাইনে:

    Batch Norm = across batch (↓ column direction) | Layer Norm = across features (→ row direction)
